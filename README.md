# Typing Master - 多语言打字练习

Multi-language typing practice application supporting French, Spanish, Italian, Portuguese, Russian, and Japanese.

Built with Electron.

## Features

- **6 languages**: French, Spanish, Italian, Portuguese, Russian, Japanese
- **Virtual keyboard**: US International (with dead keys), Russian ЙЦУКЕН, Japanese JIS kana
- **Multiple modes**: Free practice, timed challenge, precision mode
- **Difficulty levels**: A1-C1 (CEFR) / N5-N1 (JLPT)
- **Statistics tracking**: WPM, accuracy, problem characters, category breakdown
- **Built-in manuals**: Typing guides for each language's special characters

## Install

```bash
npm install
```

## Run

```bash
npm start
```

## Build

```bash
npm run build:win   # Windows NSIS installer
npm run build:mac   # macOS DMG (x64 + arm64)
```
