## 1. 安装

### 系统要求

| 平台 | 要求 |
|---|---|
| Windows | Windows 10 及以上（64 位） |
| macOS | macOS 10.15 Catalina 及以上；Intel 与 Apple Silicon 均有对应安装包 |
| 磁盘 | 约 400 MB（含安装空间） |

应用完全离线运行：不需要联网、不收集任何数据，练习记录和自定义词库只保存在本机。

### Windows 安装

1. 从 [Releases](https://github.com/CacinieP/typing-master/releases/latest) 下载 `.exe` 安装包
2. 双击运行。**Windows 未对该安装包做代码签名**，因此 SmartScreen 可能弹出「Windows 已保护你的电脑」：
   - 点击 **「更多信息」** → **「仍要运行」** 即可继续安装
   - 若需确认文件完整性，可在 Release 页核对文件大小；下载来源仅限本项目的 GitHub Releases 页
3. 按安装向导完成安装（可自定义安装目录）

### macOS 安装

1. 从 [Releases](https://github.com/CacinieP/typing-master/releases/latest) 下载对应芯片的 `.dmg`：
   - Apple Silicon（M1/M2/M3/M4 系列）→ `arm64.dmg`
   - Intel 芯片 → 不带 `arm64` 的 `.dmg`
   - 不确定芯片型号：点  左上角  →「关于本机」查看「芯片」
2. 打开 `.dmg`，将 **Typing Master** 拖入「应用程序」文件夹
3. 首次启动若提示「无法验证开发者」或「从互联网下载」：
   - 该应用已通过 Apple 公证（Developer ID 签名 + 公证票据），正常情况下 Gatekeeper 直接放行
   - 若仍被拦（常见于离线机器）：在「系统设置 → 隐私与安全性」底部点击 **「仍要打开」**

### 从源码运行（开发者）

```bash
git clone https://github.com/CacinieP/typing-master.git
cd typing-master
npm install
npm start
```

需要 Node.js 18+。

## 2. 快速开始

1. 启动 Typing Master
2. 在欢迎页面点击一种语言卡片（或在顶部导航栏选择语言）
3. 可选：调整模式、分类、难度
4. 点击「开始」按钮
5. 根据屏幕提示输入文字

### 基本操作

| 操作 | 说明 |
|------|------|
| 输入文字 | 在输入框中键入，每个字符实时反馈对错 |
| 完成一个词 | 输入完所有字符后自动跳转到下一个词 |
| 中途退出 | 按 `Esc` 键结束当前练习（也可关闭打开的弹窗） |
| 开始 / 重练 | 选好语言或在结果页按 `Enter` 键 |
| 重置进度 | 点击导航栏 ↺ 按钮 |

> 提示：练习中点击输入框以外的区域，焦点会自动回到输入框。粘贴和拖放被禁用，请实际键入。

### 界面说明

- **目标文字区**：显示当前需要输入的单词，绿色=正确，红色=错误，蓝色下划线=当前位置
- **虚拟键盘**：高亮显示下一个需要按的键
- **实时统计**：显示 WPM 速度、准确率、进度、计时

## 3. 游戏模式

### 自由练习

- 无时间限制
- 练习完所有匹配的词汇后结束
- 适合日常练习和熟悉键位

### 限时挑战

- 可选 60s / 120s / 300s
- 点击「开始」后立即倒计时，结束后自动结算
- 目标：在限定时间内输入尽可能多的正确词汇

### 精确模式

- 固定 20 个词汇
- 记录每一个字符的准确率
- 适合检测和改善打字精度

### 错词重练

每次练习结束后，结果页会列出本局打错的词（错词回顾）：

- 点击 **「重练错词 (N)」** 按钮，立刻用这些词开一局新练习
- 重练不受分类/难度筛选影响，只练打错的词
- 重练同样全对时，错词回顾不再出现

## 4. 语言与键盘布局

### 欧洲语言（法/西/意/葡）

使用 **US International** 键盘布局，通过「死键」机制输入带重音的字符。

**输入方法**：先按死键（不产生字符），再按目标字母。

| 死键 | 按法 | 产生重音 |
|------|------|----------|
| 锐音符 | `'`（撇号键） | á é í ó ú |
| 钝音符 | `` ` ``（反引号键） | à è ì ò ù |
| 长音符 | `Shift + 6` | â ê î ô û |
| 分音符 | `Shift + '` | ä ë ï ö ü |
| 波浪号 | `` Shift + ` `` | ã ñ õ |

> 提示：在应用内点击「?」按钮可查看每种语言的详细字符对照表。
>
> 应用内手册与仓库 `manuals/` 目录下的 `*-manual.md` 内容同源（法语/西语/意语/葡语/德语/俄语/日语各一份），后者供在 GitHub 上阅读与检索使用。

### 俄语

使用标准 **ЙЦУКЕН** 布局。需要在系统输入法中添加俄语键盘。

### 日语

支持两种输入模式：

- **罗马字模式**：用英文字母输入，如 `watashi` → 私。适合初学者。
- **假名模式**：使用 JIS 假名键盘布局，每个键直接对应一个假名。

可随时在控制栏切换输入模式。

## 5. 词汇管理

点击导航栏 **📚** 按钮打开词汇管理面板。

### 5.1 下载模板

1. 在「下载词汇模板」区域点击对应语言按钮
2. 浏览器自动下载 CSV 文件
3. 用 Excel、记事本或任何文本编辑器打开编辑

### 5.2 导入自定义词汇

1. 准备好符合格式要求的 CSV 文件
2. 在「导入自定义词汇」区域：
   - 选择目标语言
   - 点击「选择文件...」选择 CSV 文件
   - 点击「导入」按钮
3. 导入成功后：
   - 词汇立即替换该语言的词汇表
   - 自定义词汇自动保存，下次启动依然有效
   - 如果当前正在使用该语言，分类选择器会自动刷新

### 5.3 导出当前词汇

1. 在「导出当前词汇」区域选择语言
2. 点击「导出 CSV」
3. 下载的文件包含该语言的所有词汇，可编辑后重新导入

### 5.4 CSV 格式详解

#### 欧洲语言（法/西/意/葡/俄）

```
word,meaning,phonetic,category,difficulty
bonjour,你好,/bɔ̃ʒuʁ/,salutations,1
merci,谢谢,/mɛʁsi/,salutations,1
```

| 列名 | 必填 | 说明 |
|------|------|------|
| `word` | 是 | 要练习打字的单词或短语 |
| `meaning` | 是 | 中文释义 |
| `phonetic` | 否 | 国际音标 |
| `category` | 是 | 分类标识（如 salutations, nourriture） |
| `difficulty` | 是 | 难度等级：1=A1, 2=A2, 3=B1, 4=B2, 5=C1 |

#### 日语

```
word,reading,romaji,meaning,level,category,difficulty
私,わたし,watashi,我,N5,noun_basic,1
```

| 列名 | 必填 | 说明 |
|------|------|------|
| `word` | 是 | 汉字或假名 |
| `reading` | 是 | 假名读法 |
| `romaji` | 是 | 罗马字拼写 |
| `meaning` | 是 | 中文释义 |
| `level` | 否 | JLPT 等级（N5/N4/N3/N2/N1） |
| `category` | 是 | 分类标识 |
| `difficulty` | 是 | 难度等级：1=N5, 2=N4, 3=N3, 4=N2, 5=N1 |

#### CSV 编写注意事项

- 第一行必须是标题行（列名）
- 使用 UTF-8 编码保存
- 如果字段中包含逗号，用双引号包裹：`"s'il vous plaît,请"`
- `difficulty` 必须是 1-5 的整数
- `category` 可以自定义名称，建议用英文标识（如 `my_words`）
- 空行会被自动跳过
- `word` 和 `meaning` 为空的行为会报错并跳过

## 6. 统计系统

### 实时统计

练习过程中底部显示：
- **WPM**：每分钟正确输入词数
- **准确率**：正确词数 / 总词数
- **进度**：已完成 / 总词数
- **计时**：剩余时间（限时模式）

### 练习结果

每次练习结束后显示：
- 速度、准确率、正确/错误数、用时、总词汇数
- 错词回顾：本局打错的词及释义，可一键重练
- 数据自动保存到本地存储

### 查看统计

点击导航栏 **📊** 按钮：
- 已选择语言：显示该语言的详细统计（总练习次数、平均速度、WPM 趋势图、分类正确率、易错字符）
- 未选择语言：显示所有语言的概览

### 音效

点击导航栏 **🔇/🔊** 按钮可开关音效（默认关闭）：
- 输错字符：短促低音提示
- 完成一个词：轻快提示音
- 开关状态会被记住，下次启动保持不变

### 重置进度

点击导航栏 **↺** 按钮可重置进度。已选择语言时只重置该语言，未选择语言时重置全部，确认框中会提示实际作用范围。

## 7. 常见问题

**Q: macOS 首次启动提示「无法打开/无法验证开发者」？**
A: 该应用已经过 Apple 公证，正常联网环境下 Gatekeeper 会直接放行。离线或企业管控机器上：右键应用 →「打开」，或在「系统设置 → 隐私与安全性」底部点「仍要打开」。

**Q: Windows 安装时被 SmartScreen 拦截？**
A: 安装包当前未做代码签名，SmartScreen 会提示「已保护你的电脑」。点击「更多信息」→「仍要运行」。请务必只从 GitHub Releases 官方页面下载安装包。

**Q: 输入带重音的字符没有反应？**
A: 确保系统输入法切换到英文（US International）布局。Windows 可在「设置 → 时间和语言 → 语言」中添加。

**Q: 俄语无法输入？**
A: 需要在系统中添加俄语键盘布局（ЙЦУКЕН），并切换到俄语输入法。

**Q: 导入 CSV 后词汇没有变化？**
A: 检查 CSV 文件编码是否为 UTF-8，标题行是否正确。导入时会显示成功/错误提示。

**Q: 导入的词汇在重启后丢失了吗？**
A: 不会。自定义词汇保存在本地存储中，重启应用自动加载。

**Q: 如何恢复内置词汇？**
A: 导入 CSV 会整体替换该语言词汇（含内置词汇）。当前版本恢复方法是：打开开发者工具执行 `localStorage.removeItem('typingmaster_custom_XX')`（XX 替换为语言代码，如 `fr`、`ja`）后重启应用——Windows/Linux 按 `F12`，macOS 按 `Cmd+Option+I`（或在应用窗口内按 Alt 键唤出菜单 → View → Toggle Developer Tools）。应用内的「恢复内置词库」按钮已在规划中（见 GitHub issue #11）。

**Q: 虚拟键盘的按键提示不准确？**
A: 虚拟键盘显示的是目标语言的布局，请确保系统输入法已正确切换。

**Q: 日语假名模式下有些假名打不出来？**
A: 假名模式需要系统安装日文输入法并切换到假名输入。建议初学者使用罗马字模式。
