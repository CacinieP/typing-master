# 日本語打字手册

## 输入模式

本练习支持两种日语输入模式：

### 罗马字模式 (Romaji)
使用英文 QWERTY 键盘，按照标准 Hepburn 罗马字规则输入。适合日语初学者。
- あ → a, い → i, う → u, え → e, お → o
- か → ka, き → ki, く → ku, け → ke, こ → ko
- さ → sa, し → shi, す → su, せ → se, そ → so
- た → ta, ち → chi, つ → tsu, て → te, と → to
- な → na, に → ni, ぬ → nu, ね → ne, の → no
- は → ha, ひ → hi, ふ → fu, へ → he, ほ → ho
- ま → ma, み → mi, む → mu, め → me, も → mo
- や → ya, ゆ → yu, よ → yo
- ら → ra, り → ri, る → ru, れ → re, ろ → ro
- わ → wa, を → wo, ん → nn

### 假名模式 (かな)
使用 JIS 假名键盘布局，每个键直接对应一个假名。

| 字符 | 罗马字 | 说明 |
|------|--------|------|
| っ (促音) | 后接辅音双写 (如 kitte → きって) | 小つ |

| ー (长音) | - | 长音符 |

## 汉字识读

练习时屏幕显示：
1. **汉字**（上方大字）— 目标词汇的汉字写法
2. **振假名**（汉字下方小字）— 假名读音提示
3. **输入目标** — 罗马字模式显示罗马字，假名模式显示假名

## JLPT 级别说明

| 级别 | 难度 | 说明 |
|------|------|------|
| N5 | 初級 | 基础日常用语，约800词汇 |
| N4 | 基礎 | 基本对话能力，约1500词汇 |
| N3 | 中級 | 日常沟通无障碍，约3000词汇 |
| N2 | 中上級 | 较复杂场景理解，约6000词汇 |
| N1 | 上級 | 接近母语水平，约10000词汇 |

## Windows 日语输入法

系统中已安装 Microsoft 日语 IME。切换方式：
- **Win + Space** 切换输入法
- **Alt + ~** 在日文输入法中切换直接输入/假名输入
- 日语 IME 默认使用罗马字输入模式

## 练习建议

- 初学者建议从 N5 罗马字模式开始
- 熟悉五十音图后切换到假名模式
- 注意促音(っ)的输入：双写下一个辅音字母
- 注意拨音(ん)输入 nn 避免与后续假名混淆
- 按级别逐步练习：N5 → N4 → N3 → N2 → N1
