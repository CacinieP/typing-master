# 俄语打字手册 — 标准俄语键盘布局 (ЙЦУКЕН)
# Руководство по русской машинописи — Стандартная русская клавиатура (ЙЦУКЕН)

## 概述 / Обзор

俄语使用标准 ЙЦУКЕН 键盘布局。这与英文 QWERTY 完全不同的字符映射，但物理键位相同。

Русская клавиатура использует стандартную раскладку ЙЦУКЕН, которая отличается от QWERTY.

## 特殊字符 / Специальные символы

| 字符 | 按法 | 说明 |
|:---:|:---:|------|
| **ё** | `` ` `` 键（左上角） | 常被写为 е 但打字时要区分 |
| **Ъ** | `Shift + ]` | 硬音标 твёрдый знак |
| **Ь** | `Shift + M` | 软音标 мягкий знак |
| **，** | `Shift + .` | 逗号 |
| **。** | `/` 键 | 句号 |

## 练习建议 / Советы по практике

### 第一阶段：高频字母
先掌握最常用的字母及其键位：
- о, а, е, и, н, т, с, р, в, л

### 第二阶段：区分易混字母
- **ш / щ** — ш 在 i 键，щ 在 o 键
- **ы / и** — ы 在 s 键，и 在 b 键
- **ъ / ь** — ъ 在 ] 键，ь 在 m 键
- **е / ё** — е 在 t 键，ё 在 ` 键

### 第三阶段：完整打字
用高频词汇练习完整打字：
- привет (你好), спасибо (谢谢), Россия (俄罗斯)
- магазин (商店), университет (大学), библиотека (图书馆)

## Windows 输入法切换

- `Win + Space` 切换到「俄语 - 俄文键盘」
- 确保使用标准俄文布局（0419:00000419），不是音标布局
