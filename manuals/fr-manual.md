# 法语打字手册 — US International 键盘布局
# Manuel de frappe française — Clavier US International

## 概述 / Introduction

US International 键盘布局是 Windows 上输入法语重音字符的最佳方式。它使用「死键」(dead key) 机制：先按一个特殊键（不产生字符），再按目标字母，即可组合出带重音的字符。

Le clavier US International utilise des « touches mortes » : appuyez d'abord sur une touche spéciale, puis sur la voyelle pour obtenir un caractère accentué.

---

## 死键对照表 / Table des touches mortes

| 死键 | 按键位置 | 产生重音 | 示例 |
|------|---------|---------|------|
| `'` (撇号) | `'` 键（不按Shift） | 锐音符 aigu | é á í ó ú |
| `` ` `` (反引号) | 左上角 `` ` `` 键 | 钝音符 grave | è à ì ò ù |
| `^` (脱字符) | `Shift + 6` | 长音符 circonflexe | ê â î ô û |
| `"` (双引号) | `Shift + '` | 分音符 tréma | ë ä ï ö ü |
| `AltGr` | 右 `Alt` 键 | 直接输出 | ç œ æ |

## 法语特殊字符输入方法

| 字符 | 步骤 1 (先按) | 步骤 2 (再按) | 说明 |
|------|:---:|:---:|------|
| **é** | `'` | `e` | 最常见的法语字符 |
| **è** | `` ` `` | `e` | |
| **ê** | `^` | `e` | 先按 Shift+6，再按 e |
| **ë** | `"` | `e` | 先按 Shift+'，再按 e |
| **à** | `` ` `` | `a` | |
| **â** | `^` | `a` | |
| **ù** | `` ` `` | `u` | |
| **û** | `^` | `u` | |
| **ô** | `^` | `o` | |
| **î** | `^` | `i` | |
| **ï** | `"` | `i` | |
| **ç** | `AltGr` | `c` | 右Alt+c |
| **œ** | `AltGr` | `o` | 右Alt+o |
| **æ** | `AltGr` | `a` | 右Alt+a |

大写重音：先按死键，再按 `Shift + 字母`。例如 `É` = `'` 然后 `Shift+E`。

## 小技巧 / Conseils

1. **只想要死键本身？** 按死键后再按**空格**即可输出原字符。例如想要 `'`：按 `'` 再按空格。
2. **反斜杠？** 法语很少用到但标准键盘上就是 `\` 键。
3. **练习建议：**
   - 先练含有 `é` 的词（最常见），如 *café, été, lycée*
   - 再练 `è` 和 `à`，如 *mère, père, là*
   - 最后练 `ç` 和 `œ`，如 *français, cœur*

## Windows 输入法切换

- `Win + Space`：切换输入法语言
- 切换到「法语(France) - 美式键盘 US International」
- 确保键盘布局显示为 US International 而非标准法语布局
